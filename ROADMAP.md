# Roadmap: Trust Dependency Analyzer - Trustpkg

## MVP
- [ ] **CLI:** Command-line handling and management
- [ ] **Analyzer:** Determines analysis logic
- [ ] **Sources:** Knows where to fetch data
- [ ] **Score:** Scoring system
- [ ] **Report:** Final results

- [x] **Software architecture**
- [x] **Documentation** (README, vision, roadmap)


## Future Features

### Phase 2: Source Expansions and Integrations
- [ ] Add more reliable information sources for comparison.
- [ ] Add version comparisons and local caching.
- [ ] Integration with public registry APIs (npm, crates.io, PyPI).

### Phase 3: Artificial Intelligence and Expansion
- [ ] AI module for analyzing anomalous behavior in minor package updates (early detection of supply chain attacks).
- [ ] Expansion to different environments.

### Phase 4: Database and Advanced Dashboards
- [ ] Centralized dashboard (ASPM-lite) for Engineering Directors and CISOs.
- [ ] Organization-specific approval policies (exceptions, whitelists, SOC2/ISO27001 compliance audits).
- [ ] Executive supply chain audit reports.
